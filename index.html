About

This AI-powered resume screening system uses advanced Natural Language Processing (NLP) techniques to analyze resumes and match them with job descriptions. Built with Python Flask backend and modern web technologies.

Technologies Used:

  • Python Flask: Lightweight web framework for the backend API
  • NLTK: Natural Language Toolkit for text preprocessing
  • PyPDF2 & python-docx: Libraries for extracting text from PDF and DOCX files
